14.  Escreva um programa para conversão de temperatura. O utilizador deve escolher se

     abaixo:  
     F : Temperatura em Fahrenheit; C :Temperatura em Celsius
* Celsius-Fahrenheit: F = (9 * C + 160) / 5
* Fahrenheit-Celsius: C = (F - 32) * (5 / 9);
